# 第二輪優化紀錄

本輪以「縮短行政同工找到資料與完成判斷的時間」為核心，優化名冊、代禱與角色導覽三個高頻操作情境。

| 面向 | 本輪改進 | 預期效益 |
| --- | --- | --- |
| 宣教士名冊 | 支援姓名、服事地區、差派機構、電子郵件的即時搜尋，以及啟用／已停用狀態篩選。 | 管理者能更快定位同工檔案，並掌握篩選後的資料數量。 |
| 代禱作業 | 將清單拆為「代禱中」、「已回應」與 Admin 可見的「已歸檔」，歸檔項目可恢復顯示。 | 讓守望焦點與歷史記錄清楚分流，降低追蹤遺漏。 |
| 權限回饋 | 直接存取受限網址時，提供角色與申請授權說明，並安全導回儀表板。 | 避免角色無權限時出現無法理解的空白頁或錯誤頁。 |
| 行動版 | 名冊搜尋與狀態切換改採堆疊／橫向捲動控制項，保持按鈕尺寸與文字可讀性。 | 在窄螢幕上仍可完成常見篩選與資料瀏覽。 |

## 驗證

已執行 `pnpm check` 與 `pnpm test`；共 **6 個測試檔、13 項測試通過**。本輪新增的篩選規則已由 `shared/filtering.test.ts` 覆蓋。預覽環境當時未帶入登入工作階段，因此以未登入畫面確認登入入口；已登入的篩選操作建議由 Admin 在實際帳號環境中驗收。
