# P1 牧養工作中心設計

| 面向 | 設計決定 |
| --- | --- |
| 待辦類型 | `care_followup`、`prayer_followup`、`attendance_followup`、`general`。 |
| 核心欄位 | 標題、摘要、責任人、到期日、優先級、狀態、完成時間，以及選填的小組、成員、宣教士、代禱關聯。 |
| 角色範圍 | Admin 可管理所有待辦；Leader 僅可查看及處理「指派給自己」或「屬於其受指派小組」的待辦。Member 無存取權。 |
| 工作建議 | 從待跟進關懷、未歸檔代禱與近 30 日缺席紀錄產生「建議」，不自動建立資料列，避免未經確認的重複任務。 |
| 提醒語意 | 以逾期、今日到期、未來七日到期的工作清單作為站內提醒；本輪不寄送外部通知。 |
| 稽核 | 建立、更新、完成與略過待辦均寫入既有 audit log，摘要不包含關懷或代禱完整內容。 |
