# P1 活動 RSVP 與簽到設計

| 面向 | 設計決定 |
| --- | --- |
| 活動容量 | 在 `events` 新增選填 `capacity`；空值代表不設人數上限。 |
| 報名對象 | 使用既有中央 `people` 主檔，避免建立重複的活動聯絡人資料。 |
| 報名狀態 | `registered`、`waitlisted`、`cancelled`；根據已報名人數與容量判斷候補。 |
| 簽到 | 已報名者由 Admin 設定簽到時間；取消或候補者不可簽到。 |
| 存取範圍 | Admin 可建立、取消、簽到及檢視完整名單；Leader 與 Member 在本階段僅可檢視已發布活動。 |
| 資料完整性 | 同一人每場活動僅保留一筆報名；取消後可重新報名並依當前容量重新判定。 |
