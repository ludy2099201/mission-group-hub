# P1 上線前驗收準備設計

| 驗收主題 | 最低真實資料條件 | 通過準則 |
| --- | --- | --- |
| 待辦到期分類 | 至少三筆進行中待辦，分別設定為逾期、今日與未來七日。 | 工作中心三個提醒數字與篩選結果一致。 |
| Leader 範圍 | 至少一位啟用 Leader、一個指派給該 Leader 的小組與一位成員。 | Leader 僅見所屬小組／待辦，無法讀取 Admin 專區。 |
| 缺席建議 | 至少一場聚會及一筆缺席記錄。 | 工作中心顯示相對應的缺席跟進建議。 |
| 關懷建議 | 至少一筆標記為待跟進的關懷紀錄。 | 工作中心顯示相對應的關懷跟進建議。 |

驗收準備頁僅讀取目前資料，不會建立、修改或刪除任何牧養資料。系統將把「尚缺資料」與「可執行驗收」明確分開，協助 Admin 在導入真實資料後完成最終檢核。
