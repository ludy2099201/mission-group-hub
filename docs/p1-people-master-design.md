# P1 中央人員主檔設計

| 實體 | 欄位與規則 | 存取邊界 |
| --- | --- | --- |
| Household | 家庭名稱、主要聯絡電話、狀態與行政備註；不在本階段保存地址、身分證號、生日等高敏感資料。 | 僅 Admin 可管理。 |
| Person | 姓名、電子郵件、電話、可選家庭、狀態與時間戳記；電子郵件與電話僅用於重複偵測提示，不自動合併資料。 | 僅 Admin 可管理；後續可再分離牧養／行政欄位權限。 |
| Group Member Link | 在 `groupMembers` 加入選填 `personId`。未連結的舊資料仍可正常運作；連結後保留小組在地名冊欄位作為歷史相容資料。 | Admin 可建立與解除連結；Leader 仍透過既有小組範圍讀取名冊。 |
| 重複檢查 | 建立或更新前，若姓名、電子郵件或電話和既有啟用人員重疊，即回傳候選項供 Admin 判斷。 | 系統只提示，不自動合併或覆寫。 |
