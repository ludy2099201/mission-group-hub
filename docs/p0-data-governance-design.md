# P0 資料治理設計

| 項目 | 設計決定 | 安全邊界 |
| --- | --- | --- |
| 資料匯出 | 僅 Admin 可按資料集產生 UTF-8 CSV，瀏覽器端下載；首次涵蓋宣教、小組、出席、關懷、活動、公告、支持承諾。 | 支持者聯絡資訊與支持承諾屬敏感資料；所有匯出均寫入稽核紀錄。 |
| 稽核紀錄 | 保存操作者、動作、實體類型、實體 ID、摘要與 UTC 時間。摘要不寫入代禱／關懷完整內容或照片二進位資料。 | 僅 Admin 可讀取；匯出、角色異動、帳號啟停及資料建立／更新都應被記錄。 |
| 帳號停用 | 以 `users.isActive` 與停用時間管理；停用帳號保留歷史資料，不可呼叫受保護程序。 | 不允許 Admin 停用自己，避免管理者鎖死；帳號重新啟用後可恢復存取。 |
| 備份策略 | 本輪提供可稽核的資料匯出，作為可攜式備份與還原前的來源檔。 | 正式營運前仍需由教會指定備份頻率、保存位置、加密與還原演練責任人。 |
